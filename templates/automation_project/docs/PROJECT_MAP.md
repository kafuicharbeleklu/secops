# Project Map

- `main.py` : entree unique pour mode interactif et batch
- `app/branding.py` : branding et palette terminal
- `app/settings.py` : defaults projet
- `app/gemini_client.py` : connexion Gemini
- `app/project_shell.py` : chat, contexte memoire, statuts et UX
- `app/catalog.py` : definitions historiques du template
- `app/workflows.py` : logique historique du template
- `config/project.example.json` : exemple de configuration projet
- `workspace/` : artefacts generes
- `logs/` : journaux runtime
- `scripts/` : lancement et setup local
