## Shipped this cycle (for context)
- `FMT-05b+`: added a `reef` dark palette (from the diverse 7-colour set)
  and a `light` palette for light terminals (dark text, deeper signals;
  accent >=4.5 / error >=4.0, glyph signals at WCAG non-text 3:1, body
  text >=7:1). Palettes now declare a ground; contrast is tested per
  ground. The monochrome ramp sets were not adopted — they lack the
  distinct success/warning/error hues the signal roles need.
- `STAT`: cap the decorative prompt/toolbar frame at a 120-col reading
  width (`_frame_width`) so the border rule and statusline no longer
  sprawl edge-to-edge on ultra-wide terminals; the input buffer keeps
  full width. Matches the content cap already used in renderer.py.
- `#6`: strip right-side padding from the streamed answer at the Segment
  level (`_StripTrailingWhitespace` via `console.render_lines(pad=False)`,
  still through `console.print`) — no trailing whitespace in scrollback /
  copy-paste; line count and ctrl+o accounting unchanged; code-block
  backgrounds preserved.
- `#2b`: run_shell prompts once (the command) instead of twice — the generic
  tool(run_shell) prompt is skipped; destructive commands still DENY and plan
  mode still blocks, so no gate is weakened.
- `FMT-05`: three named palettes (paprika / ocean / vivid) selectable via
  SECOPS_THEME and the `/theme` runtime switch; each palette's four signal hues
  stay readable on the terminal ground.
- `FMT-05b`: `/theme <name>` validates its argument, restyles the prompt
  live, and persists to settings.json (`preferences.theme`); the saved
  palette is re-applied at launch unless `SECOPS_THEME` overrides it.
- `#2a`: command-aware risk label for run_shell — a benign curl shows R2/R1
  instead of a static R5, while privileged/destructive/compound commands stay
  conservative (display only; the execution gate is unchanged).
- `DIR`: deterministic hidden-directory ranking — the top candidate is now
  stable regardless of gobuster's threaded output order (score desc, then
  alphabetical tie-break).
- `#1b`: inter-turn no-progress guard — nudge (not a hard stop) when the same
  tool call repeats across turns, complementing the intra-turn convergence guard.
- **Root fix**: `28be2ec` stop aliasing real HTTP tools (`http_request`,
  `fetch_url`) into `run_shell`/curl — unblocks uploads (#1 root cause).
- `52ac72d` write relative payloads to a workspace, not the operator's cwd (#4).
- `5aeb549` escape lesson list so Rich renders review IDs reliably (#3).
- `443f314` WCAG-AA contrast + cleaner tool-result output (colorimetry + #5).
- `b2a5dbf` ignore `shell.php` write-tool artifact.
- Earlier: the 12 UX proposals (FMT-01/06, PROC-01/02/03, ANIM-01/02/03/04,
  X-01/02/03) from `docs/UX_RESEARCH_PROPOSAL_2026-09-01.md`, and the
