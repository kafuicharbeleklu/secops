## 🟠 UX / safety-signal (safety-delicate — treat with care)

### #2a — `run_shell` shows a static "R5 privileged local action" for every command
A benign `curl` and a destructive `rm` both display as R5. **Do not** lower the
tool's `risk_class` (that weakens the execution gate). Instead make the approval
card **command-aware**: reflect the actual command's risk (curl = network,
sudo/rm = high). The "http_request masqueraded as R5" half is already resolved by
the #1 alias fix.
- Component: `ui/tool_display.py` `_approval_risk_label`, permission engine
  command classification.

### #2b — Double approval for a `run_shell` command (tool + command)
Each shell command triggers two prompts: `tool(run_shell)` then
`command_exact(<cmd>)`. The redundancy drives approval fatigue → the operator
reaches for "Always allow", eroding the safety posture. Consolidate into a single
approval (the command one, which is the specific thing) without weakening the
gate.
- Component: `core/agent.py` approval flow, `ui/tool_display.py` approval prompt.
- Risk: touches the safety-critical approval path.

### FMT-05 — Light/dark theme + terminal-background detection + `/theme`
Contrast is now WCAG-AA (`443f314`), but the whole palette assumes a dark
background; on a light terminal the gold `accent` drops to ~1.5:1 (invisible).
Add named palettes (dark/light/high-contrast), background detection
(COLORFGBG / OSC 11), and a `/theme` command. The largest remaining "au-delà"
item from `docs/UX_RESEARCH_PROPOSAL_2026-09-01.md`.
- Component: `ui/theme.py`, `ui/commands.py`.

## 🟡 Polish / cosmetic

### #6 — Trailing whitespace on the streamed answer
Rich pads Markdown to the full width by design. A clean fix is a **Segment-level**
approach (`Console.render_lines(renderable, pad=False)`) that does **not** bypass
`console.print` — the earlier capture+`file.write` interception broke the
streaming render pipeline and the ctrl+o line accounting.
- Component: `ui/renderer.py` `_flush_live_text` / `_build_display`.

### STAT — Statusline overflows to full width on wide terminals
Related to the rendering pipeline; scope alongside #6.

### X-01b — Per-surface `?` help overlay
The `?` keymap is now accurate (`ae2d0cd`). A truly context-sensitive overlay per
surface (approval / pager / streaming) is invasive for little gain — low priority.

### PROC-05 — Pager for the inline ctrl+o expansion
Artifacts, task logs and session-review already page via `view_logs_overlay`;
only the intentional inline ctrl+o expansion remains, which is by design.
